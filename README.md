## 🦅 Now building: [CrowVault](https://crowvault.ai)

**379 MCP tools that generate production-ready code and config: Dockerfiles, Kubernetes, Terraform, database schemas, APIs, tests and security policies.**

Use it from Claude Code, Cursor, VS Code or any MCP client, or call it from the REST API, CLI, Python SDK or GitHub Actions.

```bash
claude mcp add --transport http crowvault https://api.crowvault.ai/mcp \
  --header "Authorization: Bearer $CROWVAULT_API_KEY"
```

- ▶️ **Try it with no sign-up:** [crowvault.ai/playground](https://crowvault.ai/playground)
- 🔑 **Free API key** (50 calls/month, no credit card): [crowvault.ai/register](https://crowvault.ai/register)
- 📦 **Official MCP Registry:** `io.github.rajeswaran140/crowvault`
- ⚙️ **GitHub Action:** [rajeswaran140/crowvault-setup](https://github.com/rajeswaran140/crowvault-setup)
- 🧰 **CLI:** `npm install -g crowvault` · **Python:** `pip install crowvault`

10 servers: AWS · Azure · GCP · Full Stack · Frontend · Database · Testing · Security · DevOps · API

Feedback and feature requests are very welcome. Open an issue on [crowvault-setup](https://github.com/rajeswaran140/crowvault-setup/issues).
